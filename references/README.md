# Reference materials

This directory contains design experiments, downloaded component sources, and legacy artifacts that are not used by the Kairos runtime.

- `source-libraries/`: upstream React Bits and TweakCN source trees.
- `design-imports/`: generated components, Stitch imports, dashboards, and UI samples.
- `legacy-artifacts/`: archived HTML, ZIP, JSON, and TSX source files kept for reference.

The active application lives in `../app/` and `../electron/`.
