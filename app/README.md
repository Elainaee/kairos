# Kairos application assets

The `app/` tree contains shared assets, themes, i18n catalogs, the legacy pages
still embedded by the Vue renderer, and the independent AI Chat and desktop-pet
windows. The default application shell lives in `renderer/`.

Run the desktop development environment from the repository root with `pnpm dev`.

If the local runtime setup is confusing, run `pnpm doctor` from the repository root.

Netease Music integration is limited to the user's own authorized account for personal learning and daily planning. Kairos does not redistribute music content or provide commercial public playback. It does not bypass Netease rights, membership, region, verification, rate limits, or unavailable-song restrictions.
