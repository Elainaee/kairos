# Kairos PRD

## 1. 产品概述

Kairos 是一款 Windows 桌面端学习与日常 schedule 管理 App。它结合日历、学习打卡、AI 陪伴、图片识别、提醒、音乐和桌面悬浮动漫小人，帮助用户管理学习任务、deadline、重要事件、心情记录和兴趣赛程提醒。

产品不应像传统待办软件一样冷冰冰，而应更像一个清爽高级的个人学习生活空间。用户每天打开它，可以看到今天要做什么、最近有什么重要安排、自己已经连续坚持了多少天，并且可以和 AI 学习搭子交流。

一句话定位：

> 一个 Windows 桌面端的清爽高级学习生活空间：用日历管理任务和日程，用 AI 陪你学习和记录心情，用悬浮动漫小人提醒你重要的 deadline、日常安排和喜欢的比赛。

## 2. 目标用户

- 学生
- 自学者
- 有考试、作业、项目 deadline 的用户
- 希望记录日常 schedule 和重要事件的人
- 喜欢 Valorant VCT 等电竞赛事、希望被提醒观赛的人
- 想要轻量 AI 陪伴学习空间的人

## 3. 平台与技术方向

### 3.1 平台

第一版只支持 Windows 桌面端。

### 3.2 推荐技术栈

- 桌面框架：Tauri 或 Electron
- 前端：React + TypeScript
- 本地数据库：SQLite
- 样式：Tailwind CSS 或 CSS Modules
- AI 能力：暂定通过豆包 API 接入，默认模型为 Doubao-Seed-2.0-mini，架构上保留切换其他模型供应商的能力
- 图片识别：通过多模态 AI API 接入
- 本地音乐播放：使用桌面端文件访问能力

### 3.3 技术取舍建议

优先推荐 Tauri：

- 安装包更轻
- 桌面能力较好
- 适合本地数据库和系统托盘/悬浮窗场景

如果团队更熟悉 Web 技术且希望开发速度更快，可以选择 Electron。

## 4. 核心体验原则

- 清爽高级：界面干净，信息层级清晰，避免杂乱装饰。
- 陪伴感：AI 和悬浮动漫小人应让用户感觉被陪伴，而不是被催促。
- 用户确认优先：AI 识别出的任务和日程必须经过用户确认后才能加入日历。
- 低压力记录：心情小记可选，学习打卡不应制造负担。
- 本地优先：第一版数据优先存在用户电脑本地。离线模式不要求完全可用，但在没有网络时，用户仍应能查看和编辑本地已有日程、任务、打卡记录和设置。
- 双主题：需要支持浅色模式和暗色模式。

## 5. 主要功能模块

### 5.1 主界面：双视图

主界面采用双视图布局。

左侧为日历视图：

- 展示月历
- 标记任务、deadline、节日、事件、比赛日程
- 标记已打卡日期
- 点击某一天后，右侧切换到该日详情

右侧为今日视图：

- 今日任务
- 今日事件
- 今日 deadline
- 今日比赛提醒
- 学习打卡入口
- 连续打卡天数
- 心情小记入口
- AI 陪伴入口

### 5.2 桌面悬浮动漫小人

悬浮小人常驻桌面左下角或右下角，用户可设置位置。

功能：

- 点击打开 App 主界面
- 有待办提醒时显示气泡
- 有 deadline 或比赛临近时展示轻量提示
- 空闲时播放轻微待机动画
- 可隐藏、关闭或调整位置

角色定位：

- 学习搭子
- 温柔陪伴者
- 日程提醒入口
- AI 聊天入口

视觉风格：

- Q 版可爱动漫风
- 可爱但不幼稚，需要适配清爽高级的主界面
- 用户后续可能提供示例图，届时以示例图作为角色方向参考

第一版可使用静态角色图 + 简单动画。后续可升级为 Live2D 或更复杂的动画角色。

### 5.3 学习打卡

用户每天可以进行学习打卡。

记录内容：

- 当天完成的任务
- 是否完成今日学习目标
- 连续打卡天数
- 可选心情小记
- 可选备注

规则：

- 心情小记可以为空
- 一天只能产生一个主打卡记录，但可以多次编辑
- 完成任意一个学习任务后，可提示用户是否打卡
- 打卡后当天日历显示打卡标记

统计：

- 当前连续打卡天数
- 本月打卡天数
- 历史打卡记录
- 已完成任务数量

### 5.4 日程与任务管理

用户可以手动添加以下内容：

- 学习任务
- deadline
- 重要节日
- 重要事件
- 观赛提醒
- 其他个人安排

日程项字段：

- 标题
- 类型：任务 / deadline / 节日 / 事件 / 比赛 / 其他
- 日期
- 开始时间
- 结束时间，可选
- 提醒时间
- 优先级
- 备注
- 是否完成
- 来源：手动创建 / AI 聊天识别 / 图片识别
- 创建时间
- 更新时间

任务状态：

- 未开始
- 进行中
- 已完成
- 已过期

### 5.5 App 内弹窗提醒

第一版使用 App 内弹窗提醒，不强依赖 Windows 系统通知。

提醒触发：

- 到达指定提醒时间
- deadline 临近
- 比赛即将开始
- 今日任务未完成，可选

默认规则：

- 普通任务：按用户设置提醒
- deadline：默认提前 1 天提醒
- 比赛：默认提前 30 分钟提醒

弹窗操作：

- 知道了
- 稍后提醒
- 标记完成
- 打开详情

提醒也可以由悬浮小人以气泡形式展示。

### 5.6 AI 陪伴

AI 陪伴优先支持学习搭子和情绪陪伴，管家助手作为次要能力。

#### 5.6.1 学习搭子

AI 可以：

- 帮用户拆分学习任务
- 根据 deadline 建议学习计划
- 鼓励用户继续完成任务
- 询问用户今天想完成什么
- 根据完成情况做简单反馈
- 从聊天内容中识别任务和日程

示例：

用户说：“我下周三要交数学作业，还要复习英语单词。”

AI 应识别：

- 数学作业，类型为 deadline，日期为下周三
- 英语单词复习，类型为任务，日期待确认

然后生成待确认日程卡片。

#### 5.6.2 情绪陪伴

AI 可以：

- 回应用户的心情小记
- 在用户压力大时给出温和建议
- 帮用户做简单复盘
- 鼓励用户休息或调整计划

限制：

- 不进行医疗诊断
- 不使用说教语气
- 不强行鸡血
- 不让用户产生必须每天倾诉的压力

#### 5.6.3 管家助手

第二阶段再增强：

- 每日总结
- 每周回顾
- 自动整理 schedule
- 根据用户习惯推荐学习时间

### 5.7 图片识别与自动生成日程

用户可以上传图片，例如：

- 课程表
- 作业通知
- 考试安排
- 活动截图
- 群聊中的 deadline 截图
- Valorant VCT 赛程图

流程：

1. 用户上传图片
2. AI 识别图片内容
3. 提取可能的任务、日期、时间、事件名称和备注
4. 显示“待加入日程”的卡片
5. 用户确认或修改
6. 加入日历
7. 到时间进行 App 内提醒

规则：

- AI 不能直接把识别结果加入日历
- 必须经过用户确认
- 识别不确定时显示“需要确认”
- 日期或时间模糊时要求用户补充

### 5.8 Valorant VCT 观赛提醒

第一版通过手动输入、聊天识别和图片识别支持 VCT 赛程。

支持内容：

- 赛事名称
- 队伍名称
- 比赛日期
- 比赛时间
- 赛区或阶段，可选
- 直播平台，可选
- 用户关注队伍，可选

提醒：

- 默认提前 30 分钟提醒
- 类型显示为“比赛”
- 日历中使用特殊颜色或图标区分

第二阶段需要支持自动联网获取 VCT 官方赛程。官方赛程网站暂定为：

- https://valorantesports.com/zh-TW/leagues/champions,game_changers_championship,vct_masters

届时可根据网站结构选择 API 接入、页面解析或订阅式同步方案。

### 5.9 音乐功能

第一版优先支持本地音乐播放。

功能：

- 添加本地音乐文件
- 支持常见本地音乐格式，例如 mp3、flac、wav、m4a，具体取决于桌面框架和音频播放库能力
- 播放 / 暂停
- 上一首 / 下一首
- 音量控制
- 当前播放状态展示
- 可在学习时保持后台播放

第二阶段接入网易云音乐，第一版不做网易云登录授权：

- 用户授权或跳转登录
- 播放歌单
- 收藏专注歌单
- 根据学习模式播放不同音乐

## 6. 数据模型草案

### 6.1 schedules

用于存储任务、deadline、事件、节日、比赛等日程项。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 本地唯一 ID |
| title | string | 标题 |
| type | string | task / deadline / holiday / event / match / other |
| date | string | 日期，YYYY-MM-DD |
| start_time | string | 开始时间，可空 |
| end_time | string | 结束时间，可空 |
| reminder_time | string | 提醒时间，可空 |
| priority | string | low / medium / high |
| notes | string | 备注 |
| status | string | todo / in_progress / done / expired |
| source | string | manual / ai_chat / ai_image |
| created_at | string | 创建时间 |
| updated_at | string | 更新时间 |
| sync_status | string | 预留同步状态 |
| remote_id | string | 预留云端 ID |

### 6.2 checkins

用于存储学习打卡。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 本地唯一 ID |
| date | string | 日期，YYYY-MM-DD |
| completed_task_ids | string | 已完成任务 ID 列表，JSON 字符串 |
| mood_note | string | 心情小记，可空 |
| note | string | 普通备注，可空 |
| created_at | string | 创建时间 |
| updated_at | string | 更新时间 |

### 6.3 ai_extractions

用于存储 AI 识别出的待确认内容。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 本地唯一 ID |
| source_type | string | chat / image |
| raw_input | string | 原始输入或图片路径 |
| extracted_items | string | AI 提取结果，JSON 字符串 |
| status | string | pending / confirmed / rejected |
| created_at | string | 创建时间 |

### 6.4 settings

用于存储偏好设置。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| key | string | 设置键 |
| value | string | 设置值 |

可存储：

- 悬浮小人位置
- 主题模式：浅色 / 暗色
- 默认提醒时间
- 音乐目录
- AI 设置
