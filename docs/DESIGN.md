# Kairos 设计说明

> 状态：当前实现基准  
> 范围：Kairos Windows 桌面端的渲染界面、共享组件和视觉资源。  
> 本文以 `app/` 中正在运行的代码为准，不继承已删除的旧 UI 评审或 AI 面板规格。

## 1. 产品气质

Kairos 是个人学习、日程、习惯、笔记、音乐与 AI 陪伴的桌面应用。界面应当安静、清晰、偏温暖，而不是将每个功能做成高对比的管理后台卡片。

- 桌面端优先；窗口最小宽度为 900px。
- 日历是主视图的视觉中心，其他能力通过顶部导航或弹层进入。
- 信息层级优先使用留白、字号、颜色和轻量分隔线表达。
- 交互反馈短促克制；减少动态效果开启后，所有过渡和装饰性动画必须弱化或停止。

## 2. 视觉基础

### 颜色

当前主题变量定义于 `app/tweakcn-theme.css`。浅色模式以暖白和灰米色为底，使用陶土橙作为主要操作与选中状态。

| 用途 | 当前色彩方向 |
| --- | --- |
| 页面底色 | 暖白纸感，接近 `#f9f7f0` |
| 浮层与输入面 | 半透明或纯白 |
| 次级底色 | 米灰、浅卡其 |
| 正文 | 深灰褐，而非纯黑 |
| 主色 | 陶土橙，接近 `#d1633c` |
| 辅助强调 | 低饱和蓝绿，仅用于少量状态信息 |
| 边框 | 低对比米灰；不使用粗重描边 |

主题支持 `system`、`light` 和 `dark` 三种模式。暗色模式仍应保留层级差异，避免把所有面板压成同一深色块。

### 字体与图标

- 正文字体：`Outfit`。
- 图标：Material Symbols Outlined。
- 标题使用中等至半粗字重；正文维持舒适行高。
- 当前应用未内置手写字体文件。新增字体须先确认授权、离线加载与中英文可读性，不能假设远程字体在离线桌面环境中一定可用。

### 圆角、边框与阴影

- 普通交互控件使用约 8-10px 圆角；播放器与主要面板可略大。
- 首选轻边框和细微阴影，不叠加厚描边、重阴影和多层嵌套卡片。
- 主要内容区域不是悬浮卡片墙；卡片只用于可重复条目、设置分组和弹层。

## 3. 页面结构

### 应用壳

- 顶部导航高度为 64px，承载品牌、模块导航、创建操作和工具入口。
- 窄窗口时保留图标和核心导航，次要文字自动收缩。
- 子页面通过共享壳加载，保持导航、主题和播放器状态一致。

### 日历主视图

- 月历使用固定七列网格和六行日期区域，日期单元格不会随内容跳动。
- 工具栏提供月份切换、回到今天与全屏查看。
- 日历内容使用半透明玻璃层，背景来自 `app/assets/calendar-backgrounds/default.jpg`。
- 日程、笔记和心情标记服务于日期浏览；避免用大面积色块遮盖日期本身。

### 日程、习惯与笔记

- 日程以日期、时间和完成状态为第一信息层级，支持拖动调整与冲突提示。
- 习惯使用紧凑的可勾选行、连续天数和热力图；完成态必须与未完成态一眼可辨。
- 笔记和心情按日期组织，使用克制的标签和小型状态标记。

### 音乐

- 底部共享播放器固定为 80px 高，采用带背景虚化的半透明玻璃质感。
- 左侧显示歌曲封面与元数据，中部为播放进度与传输控制，右侧为音量和队列操作。
- 本地音乐与网易云来源共用播放控制；封面优先使用音乐文件或服务返回的封面。

### AI 与桌宠

- AI 对话以独立聊天窗口和主窗口入口组成，不应额外堆叠成常驻的大型宣传卡。
- 桌宠为独立透明窗口，运行时图片位于 `app/assets/pets/desk-pet.png`。
- 点击桌宠可进入 AI；角色动画应轻柔，不遮挡核心工作区。
- 桌宠隐藏后，主窗口保留一个小型恢复入口。

### 设置

设置使用双栏弹层：左侧为分类导航，右侧为实际控制项。现有分类包括 General、Appearance、Reminders、Habits、Agent、Music 和 Data。

- 选择项使用下拉菜单，二元设置使用开关。
- 高风险操作，例如清空、恢复、删除凭据，必须二次确认。
- 保存状态以短暂文字反馈呈现，避免打断当前任务。

## 4. 交互与状态

- Hover、focus 与 active 状态使用颜色、底色和轻微位移提示；键盘 focus 必须可见。
- 任务和习惯只在用户勾选后进入完成态，完成结果应支持撤销或重新编辑。
- 删除操作不常驻显眼叉号；在 hover、focus 或更多菜单中暴露。
- 页面切换可使用短 View Transition；`Reduce motion` 或系统减少动态效果时禁用动画。
- 所有文本、按钮和图标均需在 900px 以上桌面窗口及较窄窗口中保持可读、不重叠。

## 5. 资源规范

| 资源 | 位置 | 规则 |
| --- | --- | --- |
| 默认日历背景 | `app/assets/calendar-backgrounds/default.jpg` | 当前主视图和播放器的共享背景。未来新增背景放入同一目录，并通过设置功能切换。 |
| 桌宠图片 | `app/assets/pets/desk-pet.png` | 唯一运行时桌宠源图；替换前需检查透明边缘和清晰度。 |
| 应用图标 | `app/assets/netease-format.ico` | Windows 打包与网易云入口使用。 |

`references/` 是保留的历史参考资料，不参与运行时，也不应被应用直接引用。

## 6. 实施守则

1. 新增界面先复用现有主题变量、图标与设置交互模式。
2. 未经确认，不修改 AI 聊天文案、桌宠菜单文案、已有角色图片或 Agent 逻辑。
3. 新增视觉资源必须放入 `app/assets/` 的明确分类目录，不能重新创建临时的 `Brainstorm/` 目录。
4. 变更布局或资源路径后，至少运行 `pnpm check`；更新桌面打包目录后再运行 `pnpm verify:dist`。
5. 本文随已合入的 UI 实现更新；探索稿、截图和外部模板应放在 `references/`，而不是混入当前设计基准。
