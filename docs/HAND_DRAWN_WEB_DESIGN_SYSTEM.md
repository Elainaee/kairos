#「纸上时光」通用 Web 软件设计规范

> 版本：1.0  
> 适用范围：效率工具、日历、任务管理、笔记、知识库、个人仪表盘、轻量 SaaS 及内容型后台。  
> 视觉关键词：纸张、手绘、克制、温暖、安静、有人情味。

## 1. 设计目标

本设计系统将传统生产力软件的清晰结构，与纸质手账的温度结合。界面应像一张被认真使用的米白色纸页：信息规整但不过度机械，线条自然但不影响操作，装饰有情绪但不抢占内容。

核心原则：

1. **先清晰，后手绘**：信息层级、点击区域与反馈必须可靠；手绘感只作用于视觉表达。
2. **低饱和、低对比、少量强调**：大面积保持安静，通过陶土橙、鼠尾草绿和雾霾蓝提示状态。
3. **留白也是组件**：使用舒展间距，让复杂软件仍有“可以呼吸”的感觉。
4. **轻微不规则，不故意潦草**：边线、图标、下划线可以有微小偏差，文字与数据必须易读。
5. **装饰服从任务**：插画、植物、胶带和纸片纹理只出现在低信息密度区域。

## 2. 品牌气质与视觉边界

### 2.1 应当呈现

- 温柔、专注、可信赖、日常陪伴感。
- 手账、铅笔、淡彩、旧纸张般的触感。
- 接近真实桌面用品的层叠关系：纸片、便签、标签、线圈本。
- 简单自然的微动效，如纸片浮起、铅笔线缓慢画出。

### 2.2 应避免

- 纯白大面积背景、强烈霓虹色、玻璃拟态和高反光渐变。
- 所有元素都做成歪斜或抖动，造成视觉疲劳。
- 用手写字体承载长正文、表格数据或关键操作。
- 过度拟物导致组件状态难以识别。
- 低对比到无法满足可访问性要求。

## 3. 设计令牌

### 3.1 色彩

| 令牌 | 色值 | 用途 |
|---|---:|---|
| `paper-base` | `#F7F3EA` | 页面主背景 |
| `paper-raised` | `#FCF9F2` | 卡片、弹窗、表单 |
| `paper-deep` | `#EEE6D8` | 选中项、侧栏强调背景 |
| `ink-primary` | `#32322F` | 主文字、主要图标 |
| `ink-secondary` | `#6E6B63` | 次级文字 |
| `ink-muted` | `#9A968D` | 占位、禁用、辅助线 |
| `line-soft` | `#D8D0C2` | 网格与分隔线 |
| `line-strong` | `#AFA695` | 卡片轮廓与焦点辅助线 |
| `sage` | `#83917E` | 成功、工作、完成状态 |
| `sage-soft` | `#DCE2D7` | 绿色浅背景 |
| `clay` | `#C97A58` | 警示、生活类标签、重点日期 |
| `clay-soft` | `#EBD3C5` | 陶土色浅背景 |
| `ochre` | `#C5A25D` | 学习、提醒、进行中 |
| `ochre-soft` | `#E9DDC0` | 黄色浅背景 |
| `mist-blue` | `#6E87A4` | 链接、周末、信息状态 |
| `danger` | `#B85F4C` | 删除、错误，仅小面积使用 |

正文与背景对比度至少达到 WCAG AA。浅色令牌只能作为底色，文字使用 `ink-primary` 或经过验证的深色版本。

### 3.2 字体

- **展示/标题**：`LXGW WenKai`, `Klee One`, `KaiTi`，用于品牌名、页面标题、日期和短句。
- **正文/UI**：`Noto Sans SC`, `PingFang SC`, `Microsoft YaHei`, sans-serif。
- **数字/代码**：`IBM Plex Mono`, `JetBrains Mono`, monospace。
- 手写字体仅用于不超过 30 个汉字的短文本；正文、表格、输入框必须使用 UI 字体。

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 32/44 | 500 | 日期、欢迎语 |
| H1 | 26/36 | 500 | 页面标题 |
| H2 | 20/30 | 500 | 模块标题 |
| H3 | 16/24 | 600 | 卡片标题 |
| Body | 14/22 | 400 | 正文、表格 |
| Small | 12/18 | 400 | 标签、辅助信息 |

### 3.3 间距与尺寸

以 4px 为基础单位，常用序列：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。

- 页面外边距：桌面端 32–48px，平板 24px，移动端 16px。
- 卡片内边距：16px 或 24px。
- 表单高度：40px；紧凑型 32px；主要按钮 44px。
- 最小点击区域：44×44px。
- 内容最大宽度：1440px；长文最大阅读宽度：760px。

### 3.4 圆角、边框与阴影

- 小控件圆角：6px；卡片：10px；弹窗：14px；胶囊标签：999px。
- 默认边框：`1px solid line-soft`。
- 手绘轮廓可用 SVG filter 或两层轻微错位边线实现，偏移不超过 1px。
- 阴影保持近乎不可见：`0 4px 16px rgba(70, 60, 45, .06)`。
- 禁止给每个组件添加阴影；优先使用纸张色差和边线分层。

### 3.5 纸张纹理

使用透明度 2%–4% 的细颗粒噪点覆盖页面；纹理不可干扰文字。建议用小尺寸无缝 WebP 或 CSS noise，单个资源控制在 30KB 内。打印、强制对比模式与减少透明度偏好下关闭纹理。

## 4. 页面骨架

桌面端推荐三段式布局：

```text
┌────────────┬──────────────────────────┬──────────────────┐
│ 品牌/导航   │ 主工作区                  │ 今日/详情/辅助区   │
│ 96–220px   │ minmax(0, 1fr)           │ 320–400px        │
├────────────┴──────────────────────────┴──────────────────┤
│ 可选：播放器、状态栏或全局快捷操作，64–88px               │
└──────────────────────────────────────────────────────────┘
```

- 左侧栏承载一级导航，当前项用 `paper-deep` 纸片背景标识。
- 主区只保留一个视觉主任务，如日历、编辑器、画布或数据列表。
- 右侧辅助区用于今日事项、详情、筛选、活动记录，不得复制主区信息。
- 底栏仅用于全局、持续性功能；普通 SaaS 可省略。

## 5. 核心组件

### 5.1 导航

- 图标采用 1.5px–1.75px 手绘描边，尺寸 20–24px。
- 导航项高度 48px，图标与文字间距 12px。
- 当前项使用浅纸片底色，可附一条铅笔式短下划线；不能只依赖颜色。
- 收起状态仍需 tooltip 与清晰的焦点顺序。

### 5.2 按钮

- **主按钮**：鼠尾草绿实底、深色文字；用于每屏唯一主要动作。
- **次按钮**：纸张底、柔和边框。
- **文字按钮**：无边框，用于低风险辅助动作。
- **危险按钮**：默认描边，确认阶段才使用红色实底。
- Hover：上移 1px、边框略深；Active：回落并轻微压缩至 98%；Focus：2px 外描边。

### 5.3 输入与表单

- 输入框保持规整，不使用明显歪斜边缘。
- 标签置于输入框上方；必填、错误与帮助文字均使用文本说明。
- Focus 使用 `mist-blue` 描边及 2px 柔和外圈。
- 错误信息紧邻字段，图标 + 文字，不只显示红边。

### 5.4 卡片与纸片

- 标准卡片：`paper-raised`、1px 边框、10px 圆角。
- 便签卡：可使用极轻微旋转（±0.35°），但交互控件保持水平。
- 线圈本卡片只用于高价值模块，一页最多一个，避免装饰泛滥。
- 卡片标题区、内容区和操作区之间用留白分隔，少用粗线。

### 5.5 标签与状态

- 高度 22–26px，左右内边距 8px，短文本不超过 6 个汉字。
- 颜色语义固定：绿=完成/工作，黄=提醒/学习，橙=生活/注意，蓝=信息/链接。
- 状态必须同时有文字或图标，确保色觉障碍用户可识别。

### 5.6 表格、列表与数据

- 数据组件优先保持简洁现代，不为追求手绘感牺牲对齐。
- 行高 44–52px；数字右对齐，描述左对齐。
- Hover 使用 `rgba(238,230,216,.55)`；选中行增加勾选标记。
- 大数据表允许固定表头、列调整与紧凑模式。

### 5.7 日历与时间轴

- 网格线使用 `line-soft`，周末以雾霾蓝文字表示，节日以陶土橙表示。
- 今天使用铅笔圆圈或浅色底，并提供“今天”文本提示。
- 日程时间轴用细线与节点组织；节点颜色对应分类。
- 月视图中的装饰插画放在空白日期区域，并设置 `pointer-events: none`。

### 5.8 弹窗、抽屉与提示

- 弹窗像覆盖在页面上的纸片，最大宽度 560px。
- 遮罩使用暖灰 `rgba(50,48,43,.22)`，不使用纯黑。
- Toast 像窄便签，停留 4–6 秒；错误提示不自动消失。
- 右侧已有辅助栏时，优先在辅助栏展示详情，减少弹窗打断。

### 5.9 空状态与插画

- 使用铅笔或蜡笔质感的单色/双色插画，颜色不超过 4 种。
- 空状态包含：发生了什么、下一步动作、一个明确按钮。
- 插画尺寸不超过容器高度的 40%，不得遮挡数据或点击区域。

## 6. 交互与动效

- 快速反馈：120–160ms；页面切换：180–240ms；抽屉：220–280ms。
- 缓动：`cubic-bezier(.2,.8,.2,1)`。
- 可使用铅笔线绘制、纸片轻抬、勾选填色等微动效。
- 禁止大幅弹跳、长时间漂浮和持续噪点动画。
- 遵循 `prefers-reduced-motion`：关闭路径绘制、位移和缩放，只保留淡入淡出。

## 7. 响应式规则

| 断点 | 布局策略 |
|---|---|
| ≥ 1280px | 三栏完整布局 |
| 1024–1279px | 窄侧栏 + 主区 + 可折叠辅助栏 |
| 768–1023px | 图标侧栏或顶部导航；辅助区变抽屉 |
| < 768px | 单栏；底部导航；复杂表格转卡片或横向滚动 |

- 移动端移除大面积装饰插画和常驻底部播放器。
- 核心动作固定在拇指易触区域，但不得遮挡内容。
- 日历在小屏切换为周视图/日程列表，不压缩完整月历到不可读。

## 8. 无障碍与内容规范

- 正文文字对比度 ≥ 4.5:1，大字 ≥ 3:1。
- 所有功能支持键盘操作，焦点可见且顺序符合视觉顺序。
- 图标按钮提供 `aria-label`；装饰插画使用空 `alt`。
- 触控目标至少 44×44px；相邻目标间距至少 8px。
- 不以颜色、位置或手绘符号作为唯一信息载体。
- 文案简短、自然、非责备式：使用“暂时无法保存，请重试”，不用“操作非法”。
- 日期和时间遵从用户区域设置，避免只写“05/12”这类歧义格式。

## 10. 开发实现建议

- 图标统一使用自制 SVG 或同一套线性图标二次风格化，不混用多套图标库。
- 手绘边框通过可复用 SVG mask/filter 实现，不为每张卡片导出位图。
- 纸张纹理放在全局伪元素中，避免重复请求与层级混乱。
- 将颜色、间距、字体、圆角映射为设计令牌，并同步到 Figma Variables、CSS Variables 或 Tailwind theme。
- 插画按场景懒加载；优先 WebP/AVIF，关键图标使用 SVG。
- 高密度业务页面提供“舒适/紧凑”显示模式；紧凑模式可弱化装饰但保持品牌色。

## 11. 页面验收清单

- [ ] 页面只有一个明确的主操作。
- [ ] 手绘元素没有降低文字、数据和表单的可读性。
- [ ] 色彩语义在所有页面保持一致。
- [ ] Hover、Focus、Active、Disabled、Loading、Error 状态齐全。
- [ ] 键盘可以完成所有核心任务，焦点清晰可见。
- [ ] 200% 缩放下内容不丢失、不重叠。
- [ ] 移动端没有把桌面三栏简单压缩成小字。
- [ ] 装饰插画不遮挡内容，也不抢占点击事件。
- [ ] 纹理与图片经过压缩，首屏性能符合项目预算。
- [ ] 在减少动效、深色/高对比偏好下有合理降级。

## 12. 一句话设计准则

**让软件像一本认真整理过、愿意每天翻开的手账：可靠地完成任务，也给人留下一点温度。**
