## 1. 网易云通用格式下载

- [ ] 登录本人网易云账号后才允许下载。
- [ ] 将 Netease_url 的核心解析与下载逻辑移植到 Node 主进程；不启动额外服务，并保留 MIT 署名。
- [ ] 支持单曲下载，以及在歌单中勾选歌曲后批量下载。
- [ ] 每次下载选择标准、无损或 Hi-Res；不可用时按 Hi-Res → 无损 → 标准降级并提示。
- [ ] 下载到系统音乐目录的 `Kairos Downloads` 文件夹；同一歌曲再次下载时覆盖旧文件。
- [ ] 随 Kairos 打包 FFmpeg，写入歌曲名、歌手、专辑和封面。
- [ ] 下载完成后自动导入本地音乐库，并加入 `kairos_download` 歌单。

## 2. AI Provider 与音乐控制

- [ ] 保留 OpenAI、豆包；新增 DeepSeek、MiMo 和自定义 OpenAI Compatible Provider。
- [ ] 支持默认 Provider/模型、测试连接、刷新模型和本地加密保存 API Key。
- [ ] 对话内可临时切换 Provider/模型，只影响之后消息；不自动切换模型。
- [ ] AI 可直接搜索和控制音乐播放：播放、暂停、切歌、音量、队列和喜欢歌曲。
