## 2. AI Provider 与音乐控制

- [x] 固定提供 OpenAI、豆包、DeepSeek、MiMo API、MiMo Token Plan，并支持创建多个具名的自定义 OpenAI Compatible Provider。
- [x] 自定义 Provider 仅接受 HTTPS、API Key 和兼容的 `/models`；支持重命名、删除及历史会话失效标记。
- [x] 支持默认 Provider/模型、模型目录刷新、逐模型工具调用验证和 Electron `safeStorage` 本地加密保存 API Key；未通过验证的模型禁止启用。
- [x] 模型消失、验证失败或 Provider 配置变化时标记不可用，并阻止发送；不自动启用新模型或切换替代模型。
- [x] 对话顶部可临时切换 Provider/模型，只影响该会话之后的消息，不修改全局默认 Provider。
- [x] Agent 设置使用 Provider 左侧列表、右侧详情的双栏布局；窄窗口支持列表与详情间直接跳转。
- [x] Firecrawl 保持原搜索与凭据链路，仅归入独立的“联网搜索”设置区域。
- [x] AI 可搜索网易云歌曲、歌单、专辑和歌手；歌曲按匹配度选择并最多回退三个可播放结果，歌手播放前 20 首热门歌曲。
- [x] 单曲立即播放并保留原队列，“下一首播放”移动或插入到当前歌曲之后；歌单、专辑和歌手结果按规则生成新队列。
- [x] AI 可直接执行播放、暂停、上一首、下一首、固定或相对音量、静音、队列增删清空及网易云喜欢同步。
- [x] AI 不改变播放模式、不跳转进度、不控制队列面板，也不参与音乐下载。
