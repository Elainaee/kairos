# AI 功能接口缺口

以下项目在当前 Electron 主进程或 `preload` 桥接层没有完整可用的接口。本轮不实现，也不在新 UI 中制作假数据或替代流程。

1. **Anthropic 与 Google Gemini 请求适配器**
   - 提供商元数据已存在，但发送与连通性测试返回 `not_implemented`。

2. **模型列表与能力动态查询**
   - 没有从提供商读取可用模型、上下文上限、文件限制及能力详情的接口。
   - 当前只能使用内置默认模型或手动输入模型 ID。

3. **原生文件发送链路**
   - 附件准备可能返回 `native_file`，但发送请求没有把该文件交给提供商适配器。

4. **应用内截图采集**
   - 没有屏幕、窗口或区域截图 IPC；只能通过文件选择器添加已有图片。

5. **模型工具调用事件**
   - `tools.query/propose/decide` 已存在，但 Provider Gateway 不接收或输出 `tool_proposal`，模型无法触发日程、任务、习惯、笔记和学习计划提案。

6. **待确认提案查询与恢复**
   - 没有列出某会话待确认提案、重启后恢复确认卡片的接口。

7. **撤销已提交数据变更**
   - 没有工具执行结果的撤销接口。

8. **会话批量清空**
   - 只有逐个删除会话接口，没有一次清空全部会话的接口。

9. **API 凭据删除**
   - 可以保存或替换 Key，但没有单独删除安全存储凭据的接口。

10. **可编辑摘要确认流程**
    - 上下文接口会直接生成并保存摘要，没有“生成预览 → 用户编辑 → 确认保存”的分段接口。

11. **完整用量与费用统计**
    - 当前仅汇总请求数、输入 Token 和输出 Token；没有按模型、时间范围过滤、价格版本与预估费用字段。

12. **消息级操作**
    - 没有按消息 ID 删除、编辑、重新生成指定回复或从某条消息分叉会话的接口。

13. **附件保留策略变更**
    - 附件创建后没有在“临时”和“保留”之间转换的接口。

14. **会话搜索接口**
    - 当前只能获取完整会话列表后在前端过滤，没有数据库级搜索、分页或游标接口。

15. **诊断导出与安全审计记录**
    - 没有脱敏诊断导出、请求数据类别审计或外发内容追踪接口。
